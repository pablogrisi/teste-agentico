# docs/engineering/specs/

Uma TSD por fatia vertical, nomeada `NNN-nome-da-slice.tsd.md` (numeração sequencial de 3 dígitos, começando em `001`). Use `.ai-dev/templates/technical-slice.md` como ponto de partida para cada uma.

A primeira TSD deste projeto (`001-...`) deve cobrir a fundação técnica — o mínimo necessário para o projeto rodar antes de qualquer feature de produto.
