# docs/engineering/decisions/

Uma decisão técnica pontual por arquivo, nomeada `NNN-titulo-curto.md` (numeração sequencial de 3 dígitos). Use `.ai-dev/templates/decision-record.md` como ponto de partida.

Diferença para o SDD: o SDD descreve a arquitetura vigente; um decision record aqui registra o momento de uma decisão específica — contexto, opções consideradas, motivo da escolha e o que foi descartado. Quando uma decisão aqui muda algo estrutural, atualize também o SDD e referencie o decision record por lá.
