# docs/product/

Fica aqui a camada de produto do projeto.

- `prd.md` — o PRD. Use `.ai-dev/templates/prd.md` como ponto de partida.
- `questoes-abertas.md` — índice consolidado de decisões de produto/arquitetura pendentes. Use `.ai-dev/templates/questoes-abertas.md`. Só crie este arquivo quando a primeira questão pendente aparecer.
- `glossario.md` — linguagem ubíqua do domínio, se o projeto tiver termos ambíguos ou compartilhados com outros sistemas. Use `.ai-dev/templates/glossario.md`. Opcional.

Nenhum desses arquivos existe ainda neste pacote — este `README.md` é só um marcador de pasta. Apague-o ou deixe-o quando os arquivos reais forem criados, como preferir.
